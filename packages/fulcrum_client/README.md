# fulcrum_client — optional, Phase 06

A pure-Dart package (no Flutter import, `dart test` green, consumable by git tag) with what
the three apps repeat: `SessionPort` (`refreshSession()` before routing, `42501` → session
expired, local `signOut` when the token is dead), `ErrorTranslator` for
`PostgrestException`, the eight console lessons, and the `no_supabase_outside_adapters_test`
template. **No data and no domain (R1):** custody, school and tax share nothing.

Refactoring, not function — it lands after the gateway is in production (card 06.1) and each
app adopts it at its own pace (card 06.2).
